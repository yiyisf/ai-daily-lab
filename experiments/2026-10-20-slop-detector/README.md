# 用正则做一个最小的「AI 腔」检测器

## 目的

今天的条目 [Qwen3-4B deslop](https://100toolkit.com/blog/deslop-model/) 用蒸馏 + LoRA 把破折号、「not X, but Y」、三连列举等写作习惯从小模型里训练掉。作者的评估核心之一是一个**基于正则的「slop score」**，按每 1000 词统计这些特征（原文称人类文本通常低于 15）。

本实验用纯 Python 标准库写一个**简化版**检测器，帮助理解这类评估指标是怎么算的、能捕获什么、又有什么局限：

1. 规则能否区分「AI 腔」样例和朴素的人类写法？
2. 只做表面后处理（例如把破折号替换成句号）能把分数降到多少？

注意：规则和权重是本实验自拟的，**不是**原项目的检测器；样例文本是本实验自行编写的合成文本。

## 步骤

1. 定义 5 条规则：破折号、「not X, but Y」句式、三连列举、高频套话词、「Great question!」式开场，每条带权重
2. 准备三段英文样例：`sloppy`（刻意堆砌套话）、`sloppy_no_dash`（只把破折号换成句号）、`plain`（朴素叙述）
3. 计算每千词加权得分，并检查：
   - `sloppy` 得分明显高于 `plain`
   - `plain` 得分低于 15
   - 去掉破折号后得分下降，但仍高于 `plain`

运行：

```bash
python main.py
```

程序最后输出 `RESULT: ...`，任一检查失败时以非零状态退出。

## 预期结果

- `sloppy` 远高于 `plain`，`plain` 接近 0
- `sloppy_no_dash` 的破折号计数为 0，总分下降但仍明显偏高——表面替换消除不了句式和用词层面的特征

## 局限与可以继续尝试

- 正则只能抓表面模式，会误报（例如正常的三项列举）也会漏报；原文作者也提到其评分是自己的检测器、没有做读者研究
- 可以把自己常用模型的输出贴进来打分，或增加规则（如 "Moreover," 开头、过度的加粗小标题）
- 可以把规则改成中文版本（如「不是……而是……」「总而言之」），看看在中文输出上的效果

## 内网复现

- **无需任何第三方依赖**，只用 Python 3.8+ 标准库（`re`），无需联网，可直接在内网运行
- 把 `main.py` 拷贝到内网机器执行 `python main.py` 即可
- 如果想对比原项目发布的模型，需要从 Hugging Face 下载权重（需要外网或内网的 Hugging Face 镜像）；没有镜像时，可以用内网已有的任意模型生成文本，粘贴进样例里打分
