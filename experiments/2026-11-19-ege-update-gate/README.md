# 玩具实验：用 EGE 统计闸门拦住「局部提分但偷偷回归」的 Agent 规则更新

## 目的

arXiv 论文 *Evidence-Governed Adoption of Self-Generated Updates in Autonomous AI Agents*（2611.16378）提出 Evidence-Governed Evolution（EGE）框架：当编码 Agent 自动修改提示词、规则文件（如 `AGENTS.md`）或工作流时，不能只看一次局部跑分就合并，而要把「生成候选」和「确认采纳」拆开，并在新鲜配对样本上同时过三道关：

1. **主目标显著提升**：用 Hoeffding 单侧下界确认提升不是随机波动，且超过预设最小增益阈值 `margin`。
2. **保护能力非劣性**：对既有核心能力（例如组件库规范合规率、回归测试通过率）做相对基线的非劣性检验，防止「拆东墙补西墙」。
3. **评测器校准**：用少量人工/参考评测抽样对比自动评测器，扣掉自动评测器的乐观偏差（optimism bias），避免候选改动靠迎合自动打分器蒙混过关。

本实验**不调用模型、不访问网络**，只用 Python 标准库，在构造的 3 个规则更新候选上模拟「无护栏直接看均值」与「EGE 三道统计闸门」的采纳差异：

- `cand_good`：主任务真实提升 +0.16，规范合规无回归，自动评测器无偏 → **应当通过**
- `cand_regress`：主任务真实提升 +0.18，但规范合规下降 -0.15 → **应当被非劣性护栏拦截**
- `cand_optimistic`：主任务真实零提升，但自动评测器对其存在 +0.18 乐观偏差 → **应当被评测器校准拦截**

## 步骤

```bash
python main.py
```

不需要安装第三方包。程序固定随机种子生成配对评测与校准样本，输出每个候选的原始均值、校准后下界、是否通过，`METRIC:` 指标、`[PASS]/[FAIL]` 检查项和最终 `RESULT:` 结论；任一检查失败时以非零状态退出。

## 预期结果

- 若只看自动评测器主目标均值，3 个候选看似都有明显提升（3/3 全部误放或放行），会放进 2 个有害/无效更新
- 启用 EGE 三道闸门后，仅 `cand_good` 通过，`cand_regress` 和 `cand_optimistic` 均被拦截，拦截率 100%

## 局限

- 所有分数都是用固定随机种子构造的仿真数据，用于验证统计闸门的逻辑，不代表真实编码 Agent 的分布
- 论文给出的是面向可数候选序列的同时下界与版本化基线替换（bridge tests）理论；本玩具脚本只实现单轮单候选的 Hoeffding 下界 + 校准偏差扣除 + 非劣性检验的核心形式

## 启示与可以继续尝试

- 团队迭代 `AGENTS.md`、Agent Skill 或提示词模板时，可以把历史常见回归项（如「是否复用已有组件库」「是否破坏已有测试」）固定成非劣性护栏集
- 若团队用开源小模型当自动评审（LLM-as-a-Judge），建议保留一小批人工复核样本定期算一次偏差校准，防止规则越改越偏

## 内网复现

- 仅依赖 Python 3 标准库（`math`、`random`、`statistics`），无任何第三方包，开发机和内网 CI 镜像均可直接运行
- 完全离线运行，不访问外网，不需要 API key 或 GPU
- 若接入真实团队评测集：将脚本中的仿真生成器替换为本地离线评测结果 JSON（`baseline` 与 `candidate` 的逐题配对得分）即可，无需外网
