# 离线编码 Agent 行为轨迹解析与异常模式识别

复现论文 [*Interpreting Coding Agents Through Their Behavioral Trajectories*](https://arxiv.org/abs/2611.17440) 的核心工程思路：不把编码 Agent 当作只看通过率的黑盒，而是用确定性规则解析器把不同脚手架（CLI 工具名与命令格式各异）的原始轨迹统一映射到 `search`、`edit`、`test`、`other` 四类高层行为，再基于行为比例与转移特征做栈画像聚类和异常模式体检（如「先盲改后不测」「重复搜索空转」）。

## 实验内容

1. **异构轨迹统一解析**：构造 3 种脚手架风格（类 Claude Code、类 OpenCode、纯 Shell CLI）共 9 条合成任务轨迹（含 51 个带真值标注的事件），覆盖正常闭环、盲改未测、搜索空转三种模式。
2. **规则映射准确率**：验证纯正则/关键词规则在不读取工具名字段、只看命令与参数语义时，对四类高层动作的分类准确率。
3. **无结果特征的栈画像检索**：仅用 6 维行为统计向量（四类动作占比、首次编辑前搜索步数、编辑后测试覆盖率），通过最近质心检索判断跨仓库轨迹所属的脚手架风格。
4. **异常轨迹自动告警**：检测两类自部署小模型常见故障——`blind_edit`（首次编辑前 0 次检索或编辑后无测试）与 `search_thrash`（连续搜索 ≥ 5 步且重复查询）。

## 内网复现

本实验完全离线，仅依赖 Python 3.11+ 标准库，无需安装任何第三方包或联网访问模型接口：

```bash
cd experiments/2026-11-23-trajectory-behavior-parser
python3 main.py
```

若要接入团队自己的编码 Agent 日志（如 OpenCode / Cline / Codex CLI 导出的 JSONL），只需把每条工具调用整理成 `{"cmd": "...", "args": "..."}` 列表传入 `parse_action()`，即可在离线内网批量统计各模型或 `SKILL.md` 改动前后的探索、编辑、测试行为偏移。
